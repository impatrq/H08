# Documentación

Cada documento está en PDF para leer y en Word para cambiarlo.

- Carpeta_tecnica: explica cómo está hecho el tablero, la placa, el programa y cómo se armó.
- Carpeta_de_campo: lo que fuimos haciendo día a día, los problemas que tuvimos y cómo los resolvimos.
- Manual_de_usuario: cómo usar el tablero. Cómo prenderlo, cómo entrar desde el celular, qué puede hacer el profesor y cómo apagarlo.
- Elementos_de_alcance_inconclusos.pdf: lo que queríamos hacer al principio y no pudimos, y por qué.
- Plantilla_de_compras_H08.xlsx: lo que compramos, cuánto cuesta y el total. También lo que nos dio el colegio y lo que pusimos nosotros.
- Anteproyecto/Proyecto_H-08.pdf: la idea del proyecto, como la presentamos al principio.
- Historias_de_usuario: qué necesita cada persona que usa el tablero: el profesor, el alumno y el que viene a verlo.

Si solo querés usar el tablero, leé el manual de usuario. Si querés saber cómo funciona por dentro o arreglarlo, leé la carpeta técnica.

Los PDF también se pueden bajar desde nuestra página: https://proyecto-h08.github.io/
